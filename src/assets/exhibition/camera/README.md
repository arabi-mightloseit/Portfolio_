# CAMERA gallery photos

Drop the photographs for the CAMERA object in this folder. Nothing else to wire up.

- Formats: jpg, jpeg, png, webp, avif
- Order: filename order, natural sort (`01.jpg`, `02.jpg` ... `24.jpg`)
- Count: 20+ works best; the grid repeats endlessly, so more is fine but not needed
- Size: export each photo at about 1600 px on the long edge, under ~400 KB, before adding it.
  The gallery shows them small. Full-size phone photos (4000+ px, several MB) are the main thing
  that can make the gallery heavy on Android.

While this folder only contains this file, the gallery shows numbered placeholder frames.
